## General Information
- This Creative Coding A2 Prototype Project is an artistic challenge that follows the concept and design of Sol LeWitt's instruction-based art.
- In this project, I translated two of LeWitt's works: Wall Drawing 935 and Wall Drawing 936.
- Code carries out the instructions of the artistic concept
- I created a pastel colour palette for both artworks 

## Technologies Used
- Processing version 4.5.6
- Python Mode in Processing

## Features
- Both artworks have a black background featuring four sections of colourful geometric shapes and are interactive.
- They differ in shapes and interactivity.  

**Wall Drawing 935**
  - Straight vertical, horizontal, and diagonal stripes.
  - Pressing the mouse moves all the colours along by one step with each click and cycles through the colour     list.    

**Wall Drawing 936**
  - Curved stripes expanding in varying directions.
  - Mouse movement alters the width of the stripe and rotates the colour list.
  - Pressing the mouse increases the stripe width while held down.
